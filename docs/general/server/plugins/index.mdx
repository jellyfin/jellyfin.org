## Installing

### Catalog

In Jellyfin, open **Dashboard → Plugins → Catalog**, choose a plugin, and select **Install**. Restart Jellyfin to load the plugin.

The official repository is available by default. To add a third-party repository, open a plugin in the [catalog](/docs/general/server/plugins/) and copy its repository URL. Add it under **Dashboard → Plugins → Repositories**, then return to **Catalog** to install the plugin.

### Manual

Download a plugin ZIP from the [catalog](/docs/general/server/plugins/) or build it from source. Extract the plugin into its own subdirectory inside the server's plugin directory, then restart Jellyfin.

The plugin directory depends on your installation:

- Linux packages typically use `/var/lib/jellyfin/plugins/`.
- Windows direct installs use `%UserProfile%\AppData\Local\jellyfin\plugins`.
- Windows tray installs use `%ProgramData%\Jellyfin\Server\plugins`.

If the plugin does not appear after restarting, check that Jellyfin can read its files. To retain plugin settings during a reinstall, keep the `.xml` files in the `plugins/configurations` directory.

To develop a plugin, start with the [plugin template](https://github.com/jellyfin/jellyfin-plugin-template).
